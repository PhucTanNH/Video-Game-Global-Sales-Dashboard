
## Reproduce model comparison
```bash
python train_models.py
```

The script evaluates eight regressors with a five-fold expanding `TimeSeriesSplit`. The stacking estimator builds its meta-features with three additional expanding chronological folds. It uses titles through 2012 for training, titles from 2013 onward for the held-out evaluation, `log1p(Global_Sales)` as the training target, and reports errors after the inverse `expm1` transform. The two platform-cumulative features are computed from earlier release years only. Model results are written under `models/`.

The final tuned XGBoost and LightGBM configurations are taken from the report; its RandomizedSearchCV search spaces were not included, so the tuning search itself is not reproduced. The holdout was already used during report development, and the report notes residual leakage risks in `Publisher_Tier` and `Num_Platforms`; treat the rerun as retrospective, not as a fresh independent test.

### Latest rerun (2026-10-02)
The deployed model was selected by training-only five-fold temporal CV: tuned XGBoost (CV RMSE 1.269M). On the report's reused temporal holdout it scored RMSE 0.970M, MAE 0.372M and R² 0.389. Stacking had a lower holdout MAE (0.365M) but a higher CV RMSE (1.295M), so it was not selected. The report's stacking RMSE of 0.942M was not reproduced by this rerun.

## Project structure
- `app.py` — Main dashboard (4 tabs)
- `train_models.py` — Reproducible temporal model comparison and artifact export
- `ADY201m_enhanced_v2.xlsx` — Enhanced dataset with 74 columns; two cumulative platform features are generated by the training script
- `models/best_model.joblib` — Model selected using training-only temporal cross-validation
- `models/*.csv` — Cross-validation, test, feature importance, and error analysis results

## Features
1. **RQ1 tab:** Genre, platform, and regional impact, feature importance, and filters
2. **RQ2 tab:** Comparison of eight regressors, temporal cross-validation, and reported tuned configurations
3. **RQ3 tab:** Genre × console generation heatmap, annual trends, and genre-level prediction errors
4. **Prediction tab:** Enter game details to predict sales, view an approximate prediction range, and receive out-of-training-range warnings
